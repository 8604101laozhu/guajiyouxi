# 装备工坊

暗黑 2 风格的装备底子：十个穿着部位、魔法/稀有/暗金命名、词缀掷骰、每次攻击在最小–最大之间重新随机。

立绘、场景和你自己的练丹素材先不接。这一层只把装备逻辑做稳，方便后面往挂机循环里塞。

## 部位

对照暗黑 2 人物界面：

- 头盔、盔甲、腰带、手套、靴子
- 项链、左戒指、右戒指
- 主手、副手（盾或单手武器；双手武器占用副手）

## 伤害

物理伤害按这个顺序算，和暗黑 2 常见拆法对齐：

1. 武器基底 min/max；无形 ×1.5
2. 只乘**武器上的** `%增强伤害`，再加上武器上的 `+最小 / +最大`
3. 装外 `%增强伤害` 与力量（近战）或敏捷（弓弩/标枪）加算后乘
4. 戒指、护甲等部位的 `+伤害` 在这之后加，不再吃武器 ED
5. 火/冰/电/毒各自掷骰，不吃 ED
6. 致命一击先判定，未触发再判定死伤，物理 ×2，两者不叠加

命中率：`clamp(200 × AR/(AR+防御) × 等级比, 5%, 95%)`。

## 本地运行

```bash
npm install
npm test
npm run dev
```

浏览器打开 [http://localhost:43147](http://localhost:43147)。

掉落、穿着和人物基底属性会写进 `localStorage`。工坊里可以强制品质、看词缀掷骰范围、对着木桩挥击核对公式。
