把生成图丢进这个文件夹，不要拖进对话。

本机在仓库根目录跑：

    npm run drop:watch -- --push

或双击根目录的 投放.cmd（会打开这个文件夹并监视）。

| 子文件夹 | 进仓库哪 |
| --- | --- |
| 走路 | W2 身体 walking |
| 攻击 | W2 身体 attack |
| 死亡 | W2 身体 death |
| 立绘 | 立绘试色 |
| 法杖/走路 等 | W4 武器层 |
| 剑/走路 等 | W4 武器层 |

也可以不建子文件夹，文件名写成 `walking-0.png`、`法杖-攻击-1.png`。

想把投放目录放到炼丹盘：复制 drop.json.example 为 drop.json，改成 `D:\\ai炼丹\\投给挂机游戏`。
