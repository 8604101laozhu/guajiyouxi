# 本机开发（推荐）

不要再用投放黑框、拖拽脚本传单张图。

## 日常流程

1. 本机打开工程：`G:\guajiyouxi\guajiyouxi`
2. **直接改文件**（代码或图片都放进工程里）
3. 双击 **`backup.cmd`** 备份到 GitHub
4. 跟我说：**备份好了**

窗口会一直开着；失败时红字留在屏幕上。

## 玩家角色图（必须带角色名）

女法师只是其中一个玩家角色。路径里要有角色目录：

```text
public\sprites\inbox\characters\nv-fashi\walking\0.png …
public\sprites\inbox\characters\nv-fashi\attack\
public\sprites\inbox\characters\nv-fashi\death\
public\sprites\inbox\characters\nv-fashi\idle\
```

| 显示名 | 磁盘目录 id（只能英文） |
| --- | --- |
| 女法师 | `nv-fashi` |

以后加新玩家角色：新建 `characters\新id\`，并在 `src/lib/sprites/characters.ts` 登记名字。

旧的无名字目录 `base_animations\` 仍可读作兜底，新图请不要再往那里丢。

怪物：

```text
public\sprites\inbox\monsters\minion\walking\
public\sprites\inbox\monsters\champion\walking\
public\sprites\inbox\monsters\boss\walking\
```

背景第 1 章：

```text
public\sprites\inbox\backgrounds\chapter-1\loop.png
```

## 第一次把完整工程弄到本机

若本机还没有仓库，在任意空目录：

```bat
git clone https://github.com/8604101laozhu/guajiyouxi.git
cd guajiyouxi
```

已有工程只需偶尔：

```bat
git pull
```

## 可选：本地预览

```bat
npm install
npm run dev
```

浏览器打开终端里提示的地址即可。
