# 本机开发（推荐）

不要再用投放黑框、拖拽脚本传单张图。

## 日常流程

1. 本机打开工程：`G:\guajiyouxi\guajiyouxi`
2. **直接改文件**（代码或图片都放进工程里）
3. 双击 **`backup.cmd`** 备份到 GitHub
4. 跟我说：**备份好了**

窗口会一直开着；失败时红字留在屏幕上。

## 第一次把完整工程弄到本机

若本机还没有仓库，在任意空目录：

```bat
git clone https://github.com/8604101laozhu/guajiyouxi.git
cd guajiyouxi
```

已有工程只需偶尔：

```bat
git pull
```

## 可选：本地预览

```bat
npm install
npm run dev
```

浏览器打开终端里提示的地址即可。
