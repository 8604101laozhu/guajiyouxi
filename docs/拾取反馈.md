## 飘字 `src/game/floaters.ts`

抄 UE 插件 HitTicker 的四条：

| 设计 | 落地 |
| --- | --- |
| 固定大小环形池，满了覆盖最老的 | `MAX_FLOATERS = 24`，`list.length` 恒定；**平行数组**存 `format` 函数，合并时能拿回原显示口径 |
| 同点连续命中合并 | `MERGE_WINDOW = 0.25s` / `MERGE_RADIUS = 34px`、同 `kind` 才合并；`amount` 类累加后 `format(count)` 重算文本、`label` 类覆盖文本，**颜色也跟最新的一件走**；`pop` 归零重放弹出 |
| 重叠规避 | `GRID_CELL = 48` 的占用格，冲突 `y -= 14`，最多 `MAX_PUSH = 3` 次（不做 n² 比较） |
| 样式数据化 | 颜色/寿命/弹出曲线都从 `spawn` 参数来；渲染层不认识 d2 |

寿命 `LIFE = 1.1s`、上浮初速 `RISE_SPEED = 46`、阻尼 `GRAVITY = 120`。
画在 **光影之后**（和 `dropLabels`/`bars` 同批）：12px bold monospace、`1 + 0.35×(1-pop)` 弹出缩放、
前后淡入淡出、3px 深色描边。

接线：拾取时在英雄上方 46px 飘 `drop.label`（品质色）；金币入账时在怪的位置飘 `＋N 金币`（金色）。

## 音效 `src/game/audio.ts`（唯一碰 Web Audio 的文件）

**内联 ZzFX micro**（Frank Force / KilledByAPixel，MIT，文件头注明）。零资源零依赖，代码即音效。
四个音效：`pickup`（拾取）、`drop`（掉落落地）、`unique`（暗金专属）、`coin`（金币）。

| 规则 | 值 |
| --- | --- |
| 主音量 | `DEFAULT_VOLUME 0.35` |
| 同音效限流 | `SAME_SFX_GAP_MS 60`（30 只怪同死不许爆音） |
| 全局并发 | `MAX_VOICES 6` |
| 懒创建 | 第一次 `play()` 才建 `AudioContext`；`state` getter 不创建（无副作用） |
| 降级 | 没有音频环境 → `state = "unavailable"`、`play()` 返回 false、**不 throw** |

## 三个坑（都踩了，而且前两个很隐蔽）

### 1. Electron 桌面条没人点 → 音效全哑

[electron#13525](https://github.com/electron/electron/issues/13525)：无用户交互的窗口里
`new AudioContext()` 永远 `suspended`。修法（`electron/main.cjs`，必须在 `whenReady` 之前）：

```js
app.commandLine.appendSwitch("autoplay-policy", "no-user-gesture-required");
```
另外 `main.ts` 开机就 `audio.unlock()`（挂机条没人点，不能等交互）。

### 2. 冷启动第一声被吞（真机第一声峰值恒为 0）

链路：`resume()` 是异步的 → 同一个 tick 里 `start()` 会被音频设备初始化吃掉。
修法两条一起上：① 预热**等 `resume()` 落地之后**再做（`unlock()` 里 `.then(warmUp)`）；
② 冷启动路径上「预热」与「放真正的音」**错开 tick**（`WARMUP_DELAY_MS = 80`）。

### 3. 峰值采样漏掉短音效（这是"第一声没声音"的假象来源）

原实现固定采两次（60ms / 140ms）。而 `pickup` 只有几十毫秒 —— **声音早结束了**，
采到的是静音，于是看起来像"没播"。改成**声音存续期间每 16ms 连采一次**，
结束后再补 `PEAK_TAIL_MS = 60` 的尾巴。

> 教训：**是测量错了，不是功能错了**。"第一声是哑的"这个结论来自不可靠的测量，
> 差点让我去改一个没坏的路径。先怀疑量具。

## 自检

```bash
DESK_FLOAT_CHECK=1 DESK_SHOT=temp/smoke/floater.png npm run desk   # 注入洋红飘字 → 数像素 + 包围盒
DESK_SFX_CHECK=1 npm run desk                                      # AudioContext 状态 + 四音效峰值 + 限流 + 静音
```

实测：

```
飘字洋红像素 118 个，包围盒 CSS(484,148) 94×9（相机 0）      飘字像素自检：通过
pickup 峰值=0.242  drop=0.175  unique=0.286  coin=0.4         音效自检：通过（4/4 第一声也出声）
限流：连播两次 pickup → false    静音后播放 → false
```

飘字探针比较位置时要**把世界坐标减相机**（`x - camX`）：本机 2560 宽恰好 camX=0，
换 1920 显示器不减就会假红。
