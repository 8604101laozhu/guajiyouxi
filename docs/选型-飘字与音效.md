# 选型：拾取飘字 + 音效反馈（先对比再开工）

规矩：任何新功能先查 GitHub 对比现成方案，再决定抄什么、怎么写。

## 1. 飘字（浮动战斗/拾取文字）

| 方案 | 体积 | 依赖 | 判定 |
| --- | --- | --- | --- |
| Phaser `BitmapText` + tween | 几百 KB | 整个 Phaser | ✗ 内核是零依赖纯 TS |
| DOM 浮动文字库（`floaty-text` 类） | 小 | DOM 层 | ✗ 和 canvas 内核不同层，每帧改 DOM |
| 教程式 `FloatingText` 类 + 数组 | 20 行 | 无 | 起点（每帧 splice、无池化、数字会叠一起） |
| **UE 插件 HitTicker 的设计** | — | — | ✔ **抄设计，不用代码** |

HitTicker（Unreal 浮动数字插件）值得抄的四条：

1. **固定大小环形缓冲**：一次性分配、永不增长；满了**覆盖最老的**，而不是丢掉最新的。
2. **同一目标连续命中合并**：30 次/秒变成"一个数字往上跳"，弹出动画每次重放。
3. **屏幕空间重叠规避**：粗粒度占用格 + 冲突往上推（不是 n² 两两比较）。
4. **样式数据化**：字体/颜色随寿命曲线/弹出曲线/弧度/描边/寿命/前缀后缀。

→ 决定：**自己写 `src/game/floaters.ts`**，但把上面 4 条全落进去。

## 2. 音效

| 方案 | 体积 | 资源文件 | 维护 | 判定 |
| --- | --- | --- | --- | --- |
| **ZzFX**（KilledByAPixel，MIT） | <1KB | **无（代码即音效）** | v1.3.2 / 2025-09 / 7k 周下载 | ✔ **采用（内联 micro）** |
| jsfxr（chr15m，Public Domain） | ~30KB | 无 | 1.2.2 / 3 年前 | 备选：借它的 preset 音色思路 |
| sfxr.js（neyric，TS） | 中 | 无 | 新 | ✗ 绑 Bun CLI |
| Howler | ~30KB | **需要音频文件** | 活 | ✗ 违反"零资源"铁律 |
| Tone.js | 200KB+ | 无 | 活 | ✗ 音乐级框架，太重 |

→ 决定：**内联 ZzFX micro**（MIT，文件头注明出处与许可）+ 每个音效一行参数数组。
零资源、零依赖、precache 后播放即时。

## 3. 必须先解决的 Electron 坑（这轮调研最重要的发现）

[electron#13525](https://github.com/electron/electron/issues/13525)：**没有用户交互的窗口里
`new AudioContext()` 会一直 `suspended`，一点声音都不会出。** 桌面条恰恰是"没人点"的场景 ——
不解决这条，写多少音效都是哑的。

```js
app.commandLine.appendSwitch("autoplay-policy", "no-user-gesture-required");
```
（须在 `app.whenReady()` 之前调用；代码里仍保留"首次按键/点击时 `resume()`"的兜底。）

## 4. 验收（音效没法"看"，必须量）

- 真机探针 `DESK_SFX_CHECK`：① `AudioContext.state === "running"`；② 播放时用 `AnalyserNode`
  采样峰值（**真的出声才会有电平**，静音是 0）；③ 打印每个音效的长度/峰值供核对。
- 飘字探针：沿用掉落物那套 —— 注入 + 数像素 + 包围盒（不撞色的标记色）。
- 单测：池化/覆盖最老/同点合并/重叠上推/寿命回收；音效在**没有 AudioContext 的环境不许崩**
  （铁律：加载失败不影响主程序）。
