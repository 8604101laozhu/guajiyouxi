# 游戏内核骨架（第一步）

参照 Deskrawl: Idle ARPG（Unity/IL2CPP，桌面底部条挂机）的架构拆完之后，按你定的四条原则搭的第一版骨架：

1. **主程序 = 核心逻辑 + 主循环**；玩家移动、射击、光影、调试都在主程序里。
2. **每个模型一个文件**，模型只放「外观 + 数据」，不放行为 —— 改模型时只需读「主程序 + 那一个模型文件」。
3. **场景布局单独一个 json**，记录坐标、旋转、是否碰撞、模型参数；主程序只按它装配。
4. **任何模块加载失败都不许拖垮主程序**：记账 + 洋红占位方块顶替，右上角常驻红色角标，F1 里列原因。

## 自动战斗内核（挂机 = 没有玩家输入）

**铁律：角色自己索敌、自己走位、自己开火。人只做装备/天赋/关卡/自动化这些决策。**
（早先"玩家移动 + 射击"的理解是错的 —— 那是操作类游戏，不是挂机。）

每帧的顺序（`main.ts` 的 `update`）：

```
updateUnits(...)        → 索敌 → 走位 → 攻击（近战直接结算 / 远程生成弹道）
updateProjectiles(...)  → 弹道飞行、撞墙消失、命中扣血
updateTransient(...)    → 挥砍弧/死亡烟到点回收
updateWaves(...)        → 清完 → 歇 2.5s → 下一波（数量递增）
world.tick(dt)          → 回收 dead 实体
同步 params + 写 stats   → 模型只认 params；HUD 只读 stats
```

| 数值 | 现在 | 在哪改 |
| --- | --- | --- |
| 英雄伤害/血 | 近战 22/220、远程 16/150 | `public/scenes/chapter-1.json` 的 `params` |
| 攻击距离 / 冷却 | 近战 26 / 0.75s，远程 220 / 1.4s | `src/game/units.ts` |
| 怪血/伤害成长 | `34×1.18^(波-1)` / `6×1.12^(波-1)` | `src/game/waves.ts` |
| 精英/首领倍率 | 血量 ×2.4/×6，伤害 ×1.5/×2.2 | `src/game/units.ts` 的 `RANK_SCALE` |
| 每波数量 / 间隔 | 3+波数（上限 12）/ 0.9s | `src/game/waves.ts` 的 `WAVE_RULES` |
| 刷怪进场点 | 英雄前方 380px | `src/game/main.ts` 的 `spawnEnemy` |

调完必须跑一次战斗自检，**25 秒击杀数应在 5~10 之间**：太低是火力不够/怪太肉，太高是没压力。

### 两个必须记住的坑

1. **静态碰撞物不能摆在交战带上。** 曾把石头放在 x=820/1520：英雄从左边被挡住够不到怪，小怪从右边也被同一块石头挡住，远程弹道还被石头吞 —— **25 秒只杀 1 个，游戏实际停摆**。现在石头挪到边缘（x=120/2430/2500），并且 `ai.ts` 有兜底：`blockedFor ≥ 1.5s` 就进入 1.5s 的 `unstuckFor` 窗口忽略碰撞挤过去。
2. **刷怪点别放屏幕最右边。** 2560 宽的条上从 x≈2520 刷、英雄在 x≈340，要 20 多秒才接触，挂机开局就是干等。现在按 `英雄x + 380` 进场，**位置由 main 决定，waves 只管节拍**。

## 加一个模型（三步）

1. 新建 `src/game/models/<名字>.ts`：

```ts
import type { ModelDef } from "../types";

const model: ModelDef = {
  id: "arrow",                                  // 必须和文件名/注册表一致
  size: { w: 24, h: 6 },                        // 逻辑尺寸
  collider: { shape: "box", w: 24, h: 6 },      // 不给就按 size 推
  anchor: { x: 0.5, y: 0.5 },                   // 原点在哪儿，默认脚底居中
  draw(ctx, t, p) {                             // t=存活秒数, p=场景里给的参数
    // 坐标系已经平移到锚点并应用了 rot/scale，在 (0,0) 附近画自己即可
  },
};
export default model;
```

2. 在 `src/game/models/index.ts` 的 `EXPECTED` 里加一行 `arrow,`（记得 import）。
3. 在 `public/scenes/*.json` 的 `objects` 里用它：`{ "id": "a1", "model": "arrow", "x": 300, "y": 200 }`。

**契约校验**（`errors.ts`）：`id` 空 / `id` 与注册表不一致 / `size` 非正数 / 缺 `draw` → 判废，换成洋红占位方块并记账，**其它模型照常加载**。

## scene.json 字段

| 字段 | 必填 | 说明 |
| --- | --- | --- |
| `version` | ✓ | 必须是 `1` |
| `bounds.w/h/groundY` | ✓ | 场景世界尺寸、地面线（模型 `y` 一般填 `groundY`） |
| `layers` | ✗ | 绘制顺序，缺省 `sky/mid/ground/entity/fx/ui` |
| `objects[].id` | ✗ | 不写自动编号（重名不去重） |
| `objects[].model` | ✓ | 必须已在注册表里，否则占位 + 记账 |
| `objects[].x/y` | ✓ | 世界坐标，必须是数字 |
| `objects[].rot/scale` | ✗ | 缺省 0 / 1 |
| `objects[].layer` | ✗ | 不在 `layers` 里会记账并按 `entity` 处理 |
| `objects[].collision` | ✗ | `true` = 静态碰撞体，会被移动/子弹挡住 |
| `objects[].params` | ✗ | 数字键值，原样交给模型的 `draw`；非数字会被忽略并记账 |

## 光影（现在怎么做的）

`render/lighting.ts`：离屏画布铺环境暗色（`ambient` 0~1）→ `lighter` 叠径向光斑（带抖动 = 火光闪烁）→ `multiply` 压回主画布。
灯位现在写死在 `main.ts` 的 `LIGHTS`（三盏：暖黄/冷蓝/粉），`3` 键可整体开关。
要换 WebGL / 法线光 / Decal，只改这一个文件，接口不动。

> 注意：离屏画布是设备像素，回贴时必须按 CSS 尺寸缩放，否则会被 dpr 再放大一次（光斑位置全错）。

## 下一步（按你定的顺序）

1. **玩家**：`src/game/player/` 输入 + 移动（左右 + 跳跃/重力）+ 射击（子弹实体、冷却、与静态碰撞体判定）——都在主程序里，玩家外观仍然是 `models/player_*.ts`。
2. **接现有数值**：实时战斗直接调 `src/lib/d2`（`damage.ts` / `quality.ts` / `generate.ts` / `farm.ts`）——一次战斗多次判定，而不是现在点一次结算一次。
3. **挂机自动化**（抄 Deskrawl 的内核）：自动跑图、自动喝药（4 格）、满载回城、自动复活、老板键。
4. **美术管线**：H3 出动作片 → `ffmpeg` 抽帧 → 品红抠图 → atlas + manifest → `models/*.ts` 里按帧贴。本地只跑后处理，不装本地视频模型（16GB 显存是死限）。
5. **热重载**：调试模式下 `R` 只重载当前模型文件（不用重启窗口）。
