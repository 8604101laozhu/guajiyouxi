# 背景半透明化 + 光照合成

桌面条挂在壁纸上，**背景必须是半透明的**，否则等于在桌面底下贴了一条黑漆。
参考游戏 Deskrawl 的做法：真透明窗口（`TransparentWindow` 用 `DwmExtendFrameIntoClientArea` 把客户区变成透明）
+ 场景里的 `FakeDesktop` / `CombatBackground` / `Vignette`。我们的 Electron 窗口本来就能真透明
（`transparent: true` + `backgroundColor: "#00000000"`），所以问题全在**渲染层有没有把画布画实**。

## 怎么调（天空和地面是两个独立旋钮）

**按方向键**：`↑` 天空更实、`↓` 天空更透；`→` 地面更实、`←` 地面更透（每次 8%）。
口诀：**上/右 = 更实，下/左 = 更透**。改完屏幕上方会弹一条黑底金框的提示（1.8 秒后淡出），
不用开 F1 面板也知道自己按对了没有。

| 方式 | 说明 |
| --- | --- |
| `↑` / `↓`（别名 `[` / `]`） | **天空**（含远山）不透明度 ±8%，默认 **62%** |
| `→` / `←`（别名 `.` / `,`） | **地 面**（地平线以下）不透明度 ±8%，默认 **62%** |
| `?bgAlpha=0.4&groundAlpha=0.7` | URL 参数（0 = 全透出桌面，1 = 完全盖住） |
| `DESK_BG_ALPHA=0.4 DESK_GROUND_ALPHA=0.7 npm run desk` | Electron 侧注入上面两个参数 |

各处透明度：

- 天空 = `bgAlpha`
- 远山 = `bgAlpha × 0.7`（叠在天空上，再实就会把壁纸压掉）
- 地面 = `groundAlpha`（**独立**，不再由天空推导）
- 月亮/星星 = 各自透明度再乘 `bgAlpha`
- 暗角 `vignette` = 顶部透明 → 边缘 `0.45 × bgAlpha` 的黑
- 角色 / 血条 / HUD / 调试面板：**不参与**，始终保持不透明

经验值：地面压到 30% 时角色会明显「浮空」（脚下没有落地感），**55% 以上才有踩在地上的感觉**；
想让地面更实按几下 `.`。天空 62% 在亮色壁纸下已经能明显透出方块与渐变。

## 两个必须记住的合成坑

### 1. 光影回贴不能用 `multiply`

`multiply` 的 alpha 公式是 `αo = αs + αb(1−αs)`：源不透明（`αs = 1`）时结果**恒等于一**，
前面辛苦画的半透明背景会被一次性糊成不透明。实测：画布 alpha 全 255，天空带 255.0（期望 158）。

改法：光影层改成「黑色 + alpha 表示压暗多少」，用 **`source-atop`**（`αo = αb`）回贴 ——
只作用在已有像素上、且不动目标透明度。灯的实现也顺着改：

1. 铺黑色，alpha = `1 − ambient`
2. 每个灯用 `destination-out` 在暗色层上**抠洞**（越亮洞越大）
3. 再叠一层带颜色的辉光（`source-over`），否则只有"变亮"没有"灯的颜色"

### 2. 分层填充会累加透明度

同一块区域被两层半透明盖住时，alpha 按 `a₁ + a₂(1−a₁)` 叠加，不是取最大值：

- 天空原来铺满整块画布（含地面区域），再叠地面 0.76 → `0.62 + 0.76×0.38 = 0.91`（实测 232/255，几乎不透）
- 远山原来一直填到画布底部，也跨过了地面区域，再叠一层

改法：**天空只铺到地平线，远山只填到地平线**，地平线以下只有地面一层。
修完：天空带 158、地面带 194（= 各自设定值）。

### 3. 暗角也会加透明度

`vignette` 用 `source-over` 盖黑，等于往边缘**加** alpha（实测边缘 228 vs 中间 158，壁纸会被压出一条暗带）。
改成 `source-atop`：只压暗颜色、不抬透明度。

## 自检（读画布像素的真实 alpha）

```bash
DESK_ALPHA_CHECK=1 npm run desk
# 打印天空带/中部带/地面带的 alpha 均值，判据：两带各自半透明(15<avg<250) 且与各自设定吻合
DESK_BG_ALPHA=0.4 DESK_GROUND_ALPHA=0.8 DESK_ALPHA_CHECK=1 npm run desk   # 分开设两个档位验一遍

# 导一张「叠在假壁纸上」的合成图，肉眼确认（亮色壁纸才看得出来）
DESK_ALPHA_CHECK=1 DESK_COMPOSITE=temp/bg-alpha.png npm run desk
```

为什么不截 `capturePage` 的图来测：窗口级截图的 alpha 会被系统合成干扰，
**画布像素的 alpha 才是渲染层真实结果**。合成图是在页面里读 `getImageData` 再叠到假壁纸上导出的，
所以它反映的是真实像素，不是示意。

实测（默认 天空 62% / 地面 62%）：

```
天空带 avg=170.0 (158~218)  期望≈158     ← 158 = 0.62 × 255
中部带 avg=174.4 (158~218)
地面带 avg=167.9 (158~255)  期望≈158     ← 255 来自 HUD 与角色
背景半透明自检：通过（天空 OK / 地面 OK）
```

两个旋钮互不干扰的实测（天空固定 62%，只压地面）：

```
DESK_GROUND_ALPHA=0.30 → 地面带 avg=95.3 (77~255)   期望≈77   ← 77 = 0.30 × 255
```
