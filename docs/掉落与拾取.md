# 掉落物落地 + 挂机拾取

击杀时不再直接塞进背包：装备**掉在地上、看得见**，挂机时自动捡起来（永不留在地上）。

## 数据流

```
击杀（main.ts settleKill）
  ├─ 金币：立刻进 stats.gold（不用捡）
  └─ 装备：loot.spawnDrop() 在怪死的位置落地
        └─ 实体带 Entity.drop = { item, label, color, quality }   ← 渲染层只认这个
挂机每帧（main.ts 主循环 → loot.updateDrops）
  ├─ 落地：自己算重力（DROP_GRAVITY 900），落地后 params.grounded = 1
  ├─ pickDelay 0.45s 内不给捡（看得见）
  ├─ 英雄水平距离 ≤ PICK_RADIUS(52px) → 拾取
  ├─ 超过 MAGNET_AFTER(3s) → 吸附飞向最近英雄（**挂机不许把掉落留在身后**）
  └─ 场上超过 MAX_DROPS(40) → 最老的按已拾取回收
       └─ 拾到的载荷 → lootBag / lootCount / stats.lastDrop（口径与原来一致）
```

**英雄全灭时掉落原地不动**（不吸附、不消失、不回收除上限外），等复活。

## 契约：载荷怎么挂上去

`Entity.drop` 由 `World.spawn({ …, drop })` **透传**（`world.ts` 的 `...input`）。
曾经是 spawn 之后手挂 `e.drop = {...}`，能跑但把坑留着 —— 见下面坑 1。

## 渲染

- 图标：`src/game/models/loot.ts`（一个模型一个文件），颜色按 `params.quality` 0~3。
- 名字：`renderer.dropLabels()`，12px monospace、居中在物品上方 14px（`pos.y - size.h - 14`）、
  颜色取 `drop.color`、**先描 3px 深色边再填色**。
- **画在光影之后**：和血条/HUD 同一批，否则会被环境光压暗（标签本身亮度 105，压到 ~50 就"看着像没画"）。

## 自检

```bash
# 行为：真的掉在地上过（不是直接进袋）、落地动画、带标签、最终被捡走、零报错
DESK_LOOT_CHECK=25000 DESK_LOOT_SHOT=temp/smoke/loot.png npm run desk

# 外观：在固定位置注入一个暗金掉落物（born 给大负数，永不成熟，留在原地），
#       关光影数「地平线以上的洋红像素」并给包围盒 —— 验的是像素，不是数据
DESK_LOOT_INJECT=1 DESK_SHOT=temp/smoke/loot-label.png npm run desk
```

实测（注入 @x=600, 锚点 y=206）：

```
地平线以上洋红像素 105 个，包围盒 CSS(539,166) 73×8；地平线以下 0 个；掉落物还在场上 true
标签像素自检：通过          ← 539~612 正好以 600 居中，166~174 = 锚点上方 32px(= size.h 18 + 14)
光影打开后同一框内标签：最亮 145   ← 洋红本身亮度 105，说明没被压暗
```

## 三个坑

1. **`World.spawn` 逐字段手抄会吞字段**：它原来把 entity 一个字段一个字段抄出来，新加的 `drop`
   直接被吞 —— 掉落图标照画、名字标签永远不出现、**还不报错**。改成 `...input` 透传 + 显式把
   `drop` 写进 `SpawnInput`，并补一条"透传断言"测试。`makeUnit` 踩过一模一样的坑。
2. **别在 spawn 之后再手挂载荷**：那样能绕过坑 1，但下一个字段照样中招（坑只会被推迟）。
3. **掉落物自检别用"出口码 0"当唯一判据**：主进程 `app.quit()` 也是 0。第一版把
   `DESK_LOOT_CHECK` 和 `DESK_SHOT` 一起用，SHOT 块 2.5s 就截图退出，断言压根没跑却"通过"。
   现在冒烟脚本要求**出口码 0 且出现哨兵行**（`掉落自检：通过`），并给探针配了专用变量（`DESK_LOOT_SHOT`）。
