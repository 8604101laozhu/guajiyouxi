# 抠图（透明底）

一句话：**W2 出的帧必须过 W3 抠图，验收通过才能进游戏。不要在游戏里补抠。**

---

## 为什么必须这么干

W2（图生视频）出来的是**纯色底**的普通图片。扩散 / 视频模型**不能输出真 alpha**——
唯一例外是 `huchenlei/ComfyUI-layerdiffuse`，但它只支持 SD1.5/SDXL，不适用本机链路。
所以正确做法是：

```
纯色底出图（W2）  →  语义抠图（W3 BiRefNet）  →  真透明 PNG  →  游戏
```

跳过 W3、或 W3 失败退回烂抠图、或直接拿带白底的图投放，在游戏里就会看到：

| 症状 | 实测数据 | 原因 |
| --- | --- | --- |
| 截图感、整块底色没删 | 不透明 **90.8%**、边缘 **98.6%** 接近纯白、半透明 **0.01%** | W3 没跑 / 完全失败 |
| 背后黑白噪点、碎渣 | 连通域 **166** 个、碎渣 **111** 个 | 烂抠图留下孤立块 |
| 边缘锯齿重 | 半透明仅 **0.42%** | 硬切、没有羽化过渡 |

这三种脏边一旦糊进角色轮廓，**后期 rembg 救不回来**——只能回 W3 重出。

## 门禁：进游戏前跑一次

```
check-alpha.cmd <角色文件夹>
check-fashi-alpha.cmd          （法师专用，读 mage-src.txt）
```

或者直接命令行：

```
python scripts\check-sprite-alpha.py "D:\ai炼丹\香草社\人物生成图\法师1新"
```

- **全是 PASS** → 可以进游戏（继续用 `push-mage.cmd` / `拖到 push-mage.cmd`）
- **有 FAIL** → 回「动作循环」页面重跑 W3 BiRefNet，再导出一次，**不要直接投放**

`push-mage.cmd` / `push-mage.ps1` 已经内置这道门禁：**验收不过直接中止，不会拷贝、不会提交**。

退出码：`0` = 通过；`1` = 有 FAIL；`2` = 用法/环境错误。

## 验收标准

阈值定义在工具箱 `pages/phone/matting_w3.py`（单一事实来源），
门禁脚本 `scripts/check-sprite-alpha.py` 默认直接调用它的 `check_frame`。

| 指标 | 通过条件 | 不通过说明 |
| --- | --- | --- |
| alpha 通道 | 存在且以 `A` 结尾 | 不是真透明 PNG |
| 全透明占比 | ≥ **15%** | 背景基本没删掉 |
| 不透明占比 | < **60%** | 主体外还有大块底色 |
| 边缘纯白占比 | < **25%** | 有白边 / 白晕 |
| 孤立碎渣数 | < **20** | 背景有噪点 / 碎块 |
| 独立主体数 | = **1** | 拼图 / 多角色，不是单角色帧 |

### 指标定义的两个坑（别踩）

1. **碎渣不能用「`alpha>=250` 的 4 连通小块」判。**
   软 alpha 的角色轮廓本身就是锯齿状，会沿边缘产生几百个 <30px 的孤立 4 连通块。
   实测这样会把 BiRefNet 干净的输出误报成 **476 个碎渣**。
   正确做法：在中间阈值 `alpha>=128` 下取 **8 连通**，只有「面积 < 64px」**且**
   「离主体 > 4px」的孤立块才算碎渣。

2. **必须单独查「独立主体数」。**
   主体数 = 中间阈值下面积 ≥ `max(64, 主体面积*2%)` 的连通块个数。
   这个指标能直接抓出 2×2 拼图 / 多角色图 —— 实测旧目录里就有一批这样的帧
   （抠图前 16 个主体、98 个碎渣），直接把它们挡在投放之前。
   **拼图是源图问题，任何抠图算法都救不了，只能换单角色立绘重出。**

## 出图提示词里的背景要求

源头背景越干净，W3 越好抠。工具箱的「动作循环」页面已经把下面这些
**写死进每一帧的提示词**（`workflows/walk-cycle/prompts.json` 的 `backdrop_prompt`）：

- 纯色平涂背景（`pure white` 或 `pure chroma-key green (#00FF00)`，UI 可选）
- 无渐变、无纹理、无噪点、无暗角
- 无地面、无地平线、无投影、无接触阴影、无脚下 AO
- 干净剪影、边缘锐利、角色与背景完全分离、轮廓无白边/色溢
- 无杂物、无粒子、无速度线、无论文水印、无边框、无 UI

另外还有一段 `single_subject_prompt` 放在提示词**最末尾**（模型对最后一句最敏感），
显式禁止 character sheet / sprite sheet / grid / collage / multiple poses，
防止一帧里出好几个角色。
