# 选型：系统托盘图标

用户要求：「给游戏添加一个图片放在隐藏的图标里面，看一下 GitHub 做法」。

先对齐一下词：**「隐藏的图标」= Windows 通知区域的隐藏区**（任务栏右下角 `^` 展开的那一格）。
新装的托盘图标默认就搁在那儿。

**这件事要补的洞是**：本工程是 `skipTaskbar: true` 的透明贴边条 —— 它**关掉之后没有任何常驻入口**，
想再看到它只能去双击 `打开游戏.cmd`。托盘图标就是那个常驻入口。

## 二、Electron 官方的三条硬规矩（直接决定实现）

1. **Windows 上用 ICO**。原文：*"It is recommended to use `ICO` icons to get best visual effects."*
   PNG 在 Windows 托盘里会糊、有锯齿。→ 图标必须是多尺寸 `.ico`。
2. **不要依赖 `click` 事件，始终挂 context menu**。
   Linux 的 StatusNotifierItem 规范没规定哪个动作算「激活」，`click` 在有的环境是单击、有的是双击。
   **菜单是唯一跨平台一致的入口。**
3. **`window-all-closed` 里不能 quit**，应用和托盘才活得下去。
   本工程现在是 `app.on("window-all-closed", () => app.quit())` —— **加托盘必须动这一行**。

另：`new Tray(image, guid)` 的 `guid` 能让 Windows 记住托盘图标在隐藏区里的摆放位置，
但官方**强烈建议只配合「已代码签名」的可执行文件**使用。本工程没有签名 → **不传 guid**。

## 三、图片从哪来（**需要你定**）

工程里现成的图一个都不能直接用：

- `src/app/favicon.ico` 是 **Next.js 默认图标**（白三角 / 黑底），不是我们的；
- `public/sprites/**` 是 400KB~1MB 的**角色动画帧**，尺寸与形状都不适合做 16~32px 的图标；
- `public/sprites/inbox/stills/` 是**空的**（只有「放到这里.txt」）。

三个方案：

| 方案 | 做法 | 优点 | 代价 |
| --- | --- | --- | --- |
| **A. 程序生成（我推荐）** | 加 `scripts/make-tray-icon.mjs`：黑底 + 金色符文/法杖，直接画像素并导出 **16/24/32/48/64 多尺寸 `.ico`** | 零素材依赖；跟本仓库「模型全部程序实现」一路；配色随时改 | 要写 40~60 行生成脚本 |
| **B. 从法师帧裁头像** | 从 `inbox/characters/nv-fashi/idle/01.png` 裁头部方块 → 缩到多尺寸 → 合成 `.ico` | 一眼就是游戏形象 | 得人工确认裁哪帧、裁多大；换角色要重裁 |
| **C. 你给一张图** | png 丢进 `drop/`，我用脚本转多尺寸 `.ico` | 最贴合你想要的 | 等你出图 |

> 三个方案**都需要**一个生成/转换脚本（把一张图变成多尺寸 `.ico` 这件事本身就得写脚本）——
> `Evanfan007/desktop-pet` 也是这么干的。所以差别只在「源图从哪来」。

## 四、落地设计

### 1. 图标资源

`electron/assets/tray.ico`（多尺寸 16/24/32/48/64）。
放 `electron/` 下而**不是** `public/`：它是主进程资源，不该被当 web 静态文件取。

### 2. 新模块 `electron/tray.cjs`

照本工程既有分工（`ontop.cjs` 管置顶、`window-state.cjs` 管状态文件 —— 一个关注点一个文件）：

```js
createTray({ getWindow, onQuit, onToggleOnTop, onToggleMute, onShowHide })
```

菜单项（对齐已有那几个 chip 的能力）：

```
显示 / 隐藏游戏条        ← 第一项，也是最常用的
────────────
📌 置顶
🔊 声音
────────────
退出
```

- **单实例**：重复 `createTray` 先 `destroy` 旧的（否则隐藏区会堆一排图标）。
- **可注入**：`Tray` / `Menu` / `nativeImage` 都从参数进来，方便单测（本工程单测连 canvas 都用 Proxy 假 ctx）。

### 3. `main.cjs` 的改动

- `window-all-closed` 不再 `app.quit()`（托盘要活着）。
  但要**保证还能真的退出**：托盘「退出」与 `Ctrl+Alt+Q` 都走 `app.quit()`，
  并在 `will-quit` 里 `tray.destroy()`（不 destroy 会残留一个点不动的死图标）。
- **「✕ 关闭」按钮的语义**：它现在是 `app.quit()`（真退出）。
  加托盘之后**建议改成「收进托盘」**（窗口 hide、进程活着）—— 这正是 hermes-agent #51376 的做法，
  按钮文字也该从「✕ 关闭」改成「✕ 收起」。
  ⚠️ 这是**行为变更**（昨天刚加的按钮），要你点头；不改也行，托盘就只当额外入口。

## 五、明确不做（记下来免得以后重复讨论）

- **不传 `guid`**：官方要求配合代码签名，本工程没签名。
- **不用 `displayBalloon`**（托盘气泡）：Windows 上已被系统通知取代，`Notification` 才是正路；
  真要做提醒另开一轮。
- **不为 Linux/macOS 适配图标格式**：本工程只跑 Windows 桌面条；`Template Image` 那套（macOS）跳过。
- **不做「开机自启」**：那是另一个话题（注册表/快捷方式），跟托盘图标没有必然关系。
